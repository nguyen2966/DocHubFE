Desired product flow to preserve:

   - render PDF with Apryse
   - fixed zoom rate 1.25
   - comments render as highlight when visualState is highlight
   - comments render as point/avatar marker when visualState is point/degraded
   - sidebar/comment overlay works

2. Comment creation:
   - user selects text
   - temporary highlight anchor appears
   - pending comment composer opens
   - saving comment persists anchor data
   - canceling removes temporary anchor

3. Edit mode:
   - entering edit mode disables/hides comment anchors to avoid misleading highlights
   - Apryse ContentEdit mode starts correctly
   - comment sidebar/composer should be closed/cancelled when edit starts

4. Save edited PDF:
   - force Apryse content edit blur/commit before export
   - collect editedRects
   - compare editedRects with existing comment anchor rects
   - degraded/overlapped comments become point markers
   - non-overlapped comments stay highlights
   - send edited PDF blob + editedRects + degradedAnnotationIds to backend

5. Cancel/discard edit:
   - local Apryse edits should not remain visually if user discards
   - viewer should return to original loaded PDF state

6. Do not break:
   - page navigation
   - current page/page count
   - comment selection/thread opening
   - share/document detail layout
   - permission-driven toolbar behavior
